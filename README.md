#### Recent Projects

- My [portfolio website](https://tjarosar.io) built to be highly responsive and visually engaging, styled after Half Life 2 menus. A developer mode reveals a console with additional interactive elements. Written in React, TypeScript, Three.js, Vite.

- The potassium consortium, [bananabre.ad](https://bananabre.ad) is a collaborative environment for experimentation and hosting software projects. Mimicking the GRUB bootloader and Windows 98 UI, the desktop is fully interactive and allows users to open projects as applications from the desktop environment. Written in React, TypeScript, Three.js, Vite.

- [Wayfarer](https://apt.bananabre.ad/wayfarer/) is a first-person 3D desktop environment for Linux, built around its own wlroots-based Wayland compositor. Application windows are surfaces inside a navigable 3D world — wall panels, floating screens, and objects placed in rooms — rather than rectangles in a flat desktop stack. Written in C++, QML, Javascript, Claude Code. See the [docs](https://apt.bananabre.ad/wayfarer/docs/) for more information. Standalone distribution coming soon™

- Designed and built a custom home lab server from the ground up, selecting compatible hardware components and configuring a TrueNAS Scale environment to host multiple applications and docker containers for various development and testing purposes. The server runs a mix of software engineering tools and services, providing a versatile local infrastructure for project development, experimentation, and learning in a self-managed environment.

- Assembled a dedicated AI homelab server optimized for local model inference with two NVIDIA RTX 3090 GPUs. The setup supports a flexible AI development environment for testing, fine-tuning, and deploying models without reliance on cloud services. Airgapped for enhanced security and privacy.
